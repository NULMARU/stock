기준: [개발계획](simulation-lab-development-plan.md), [모델 검증 설계](simulation-model-validation.md).
상태는 전부 **계획됨**이다. 이번에 실제 구현된 항목은 없다. 역할은 작업 성격을 뜻하며 추가 인력 투입이나 에이전트 병렬 실행을 전제하지 않는다.

2026-09-13 갱신: 관심 종목 재무제표 기능을 FR0–FR3로 추가했다. FR0은 후속 최신 조회 요구를 반영한 서버 API 범위다. [재무제표 세부 계획](financial-statements-feature-plan.md)의 FS01–FS12가 인수 범위다. 아래 기존 P0–P5의 추정에는 FR 작업이 포함되지 않는다.

## V1 이후 별도 범위

월별 모델, 다중 지역 교역 네트워크, 우주·방산 모델, 회사별 매출 노출 모델, Recharts 3 전환, 서버 배치 실행, 계정·동기화는 각각 독립된 변경으로 추진한다. API·단위·검증 데이터가 확보됐을 때 범위를 산정한다. V1 일정에 해당 기능들이 완성되는 것으로 계산하지 않는다.

작업일 합계: P0–P3 **22–32일**, P4–P5 포함 **36–53일**. 수집·도메인 검토 대기와 사용자 배포 일정은 별도다. 데이터 확보가 지연되더라도 앱 기능과 구조 검증은 진행하고, 지연된 경험적 검증의 상태를 결과 문서에 남긴다.

**FG3:** 기업 모델 계산 단위·기간·현금 원장·불완전 입력 처리가 검증되고 Stock 재무 요약과 랩 실행의 기준 버전이 일치한다. 월별 만기 분석은 별도 월별 자료·모델 없이는 노출하지 않는다.

FR 추가 합계 **31–46 작업일**, 기존 산업 랩 36–53일과 순차 단순 합계 **67–99일**이다. FR0+FR1(20–30일)을 재무 기능의 첫 출시로 우선 개발한다. 지원 발행회사 요청 시 수집 API는 FR0에 포함하며 중국·홍콩 전면 자동화와 금융업 전용 지표는 별도 범위로 추정한다.
