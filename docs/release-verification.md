# 2026-09-13 직접 보완 릴리스

## Kimi 결과 평가

원본 엔진 격리, 순수 코어 계약, 테스트 기반은 재사용할 가치가 있었습니다. 당시 화면·Worker·실제 정규화/서버·배포는 완성되지 않았고, 버전 검사·정규화 입력 해시·재현성·금액 단위 등의 보완이 필요했습니다. Kimi의 이용량 제한 이후 사용자 요청에 따라 Codex가 직접 구현했습니다.

## 이번 구현 범위

- 별도 lazy `/lab`: 기본 14 / 전체 42 입력, 분기 범위, 6종 사건, Worker 실행/취소, 8개 지표 표·매출 그래프·현금 원장, IndexedDB 자동 저장·복제, 체크섬 JSON 내보내기/가져오기, 공유 주소, 같은 기간 최대 4개 실행 비교.
- Structural v2: FP16 환산 가정을 명시하고 디지털/물리 매출 USD B 단위를 일치. 전력·메모리·대역폭·패키징 제약과 신규 설비 공급 한도, 투자 약정/준공 원장, 영구 설비 손실/일시 전력 중단 구분. 결과는 관측자료로 보정하지 않은 조건부 구조 실험.
- 수요 성장률 ±20% 가정 범위: seed 42 / 250회 / 0~0.5 상한, P10/P50/P90. 표본은 사용자 가정 분포이며 예측 확률이 아님. 이 범위 표 자체의 영속 보관·다변수 분포 편집 UI는 후속.
- 종목 재무제표 경로, 재무 관심 목록, 연간/분기/TTM 선택, 3대 재무제표와 12개 질문, 근거 링크/계산 보류 상태, 분리된 시세 시각, 명시적으로 선택하는 가상기업 학습 화면.
- SEC/DART 수집 어댑터, 규칙 분석, 버전별 보관본, 영속 작업 중복 제거/재시도/TTL, 서버 전용 비밀값, Docker 배포 파일.
- Pages CI에 테스트·패키지/서버 타입 검사 추가. Lab/재무/Worker 별도 청크. PWA 캐시 삭제를 Stock 접두어로 제한하고 새 SW가 활성 계산 중 강제 교체되지 않도록 변경.

## 검증

- 버전 불일치·취소 거부, 입력 복제/불변성, 반복 실행 해시, 사건 표시 순서, UTF-8 경계.
- 무전력/무수요, 전력 회복과 설비 영구 손실, 칩/메모리 없을 때 준공 제한, 투자 현금 단일 차감, 기존 프로젝트 지연, 30개 유효 입력 조합 불변식.
- 평균자본/재고/채권, 지배기업 귀속 일치, 누락 CAPEX, 음수 자본, 회계 대사, 기간/통화 불일치, TTM 잔액/흐름 구분.
- 동시 요청 중복 제거·프로세스 재시작·429 실패 보관본·소진 작업 backoff·SEC 공시 컷오프·DART 누적 사실 보존.

빌드 및 패키지/서버 타입 검사 통과. 전체 ESLint는 기존 UI의 9개 오류와 2개 경고가 남아 있습니다(MyJudgmentPanel, shadcn UI export, sidebar random render). 이번 신규 코드의 린트 오류는 없습니다. 기존 주식 번들의 대형 청크 경고도 남아 있으며 이번 내부 앱은 별도 로딩됩니다.

## 후속 정확도·확장성 게이트

기존 전체 로드맵은 장기 계획이며 이번 배포로 모두 끝났다고 간주하지 않습니다. 실제 SEC/DART 대사 표본, 시세 제공자 연결/복수주식종류 범위, 원문 보존/정정 비교, 기업별 현금 시나리오, 관측 보정 및 홀드아웃 평가, 다변수 민감도 UI, AI 주석 근거 추론, 운영 DB/부하 테스트는 다음 단계입니다. 인증키/운영 환경 없이 이를 완료로 표시하지 않습니다. 세부 운영 준비는 `deployment-and-data.md` 참고.

브라우저 검증: 실제 production 빌드를 ego-browser에서 실행. 데스크톱·768·360 장치 폭에서 확인했으며 결과 표의 grid 최소폭으로 발생한 모바일 가로 넘침을 수정했습니다. 실제 Worker 계산 성공, 기기 저장, 가상기업 표시/12개 카드, API 미설정 상태를 확인했습니다. 로컬 API 18787 포트에서 health, 회사 식별, 202 작업 생성, DART 키 미설정 보관 상태를 확인했습니다.
